# Phased Plan — Stargoose Cracktro STE

Each phase is a checkpoint with a concrete **Done when** criterion. No phase writes
code for the next — we verify each increment runs in Hatari before moving on.

## P0 — Hello ST (foundation)

**Goal:** A `.PRG` boots in Hatari, shows a red screen, exits cleanly on ESC.

**New files:**
- `src/main.s` — minimal: supervisor entry, set low-res, fill screen red, wait key, Pterm0
- `src/constants.s` — first hardware equates (`$FF8240`, `$FF8260`, VBL/HBL vectors, GEMDOS/XBIOS trap numbers)
- `src/macros.s` — `SUPERVISOR_ENTER`/`EXIT`, `WAIT_VBL`, `SET_COLOR_IMM`
- `src/system.s` — `SetSupervisorMode`, `ResetUserMode`, `ExitProgram` (patterns lifted from stvirus template)
- `tools/build.py` — `uv run tools/build.py [--run|--clean]`: asset-conversion stubs, VASM invocation, optional Hatari launch
- `pyproject.toml` — uv project config, Pillow dependency
- `.gitignore` — `build/`, `__pycache__/`, etc.
- `README.md` — one-page: what/how to build

**Done when:** `uv run tools/build.py --run` → Hatari opens → red screen → ESC → clean TOS exit.

## P1 — Interrupt plumbing

**Goal:** VBL handler firing at 50 Hz, HBL handler stubbed, ESC poll in main loop.

**New files:**
- `src/vbl.s` — handler: save regs, increment `vbl_counter`, RTE
- `src/hbl.s` — handler stub (just RTE for now)

**Modifications:** `system.s` gains `InstallInterrupts` / `RemoveInterrupts`. `main.s` main loop becomes `WAIT_VBL; Bconstat; if ESC bra Exit`.

**Done when:** border flashes color cycling (visual proof VBL fires at 50 Hz), ESC exits cleanly.

## P2 — Static background (logo + stars)

**Goal:** Hatari shows the logo + stars at boot, from a baked bitmap.

**New files:**
- `tools/png2planar.py` — PNG → 4-bitplane interleaved planar + 16-color palette extraction (asserts ≤16 colors, width divisible by 16)
- `src/data/background.s` — `incbin 'build/background.bin'` + `dc.w` palette
- `src/screen.s` — `InitScreen` (set low-res, install palette, set screen base to aligned buffer, blit background)

**Asset pipeline (in `tools/build.py`):** crop top ~70 lines of `background.png` → `build/background.bin`.

**Done when:** top half of screen shows BLADE RUNNERS logo + stars exactly as in the PNG.

## P3 — Raster gradient via HBL

**Goal:** Bottom half of screen displays blue→red gradient generated by per-scanline palette writes, not baked bitmap.

**New files:**
- `tools/gradient2raster.py` — `gradient.png` → list of ~130 $0rgb words (one per scanline of the bottom half)
- `src/data/gradient.s` — `dc.w` table of gradient colors + `gradient_length`

**Modifications:** `src/hbl.s` — implements the per-line color 0 write; increments a pointer into `gradient_table` on each HBL, resets on VBL.

**Done when:** bottom half shows the gradient; color 0 in top half is still black (no visible change to logo/stars).

## P4 — SNDH music

**Goal:** Thrust plays from boot.

**New files:**
- `src/music.s` — wrappers: `MusicSndhInit`, `MusicSndhPlay`, `MusicSndhExit`. Ported from stvirus template but simplified (single SNDH, no table indexing). `song number 1` in `d0` for init.
- `src/data/music.s` — `music_sndh_file: incbin 'assets/thrust.snd'` + `even`

**Modifications:** `main.s` calls `MusicSndhInit` after interrupt install. `vbl.s` calls `MusicSndhPlay` (after `tst.w MusicIsInited`). `ExitProgram` calls `MusicSndhExit`.

**Done when:** music plays while gradient + logo display; no glitches on ESC exit.

## P5 — Font + single-row scroller

**Goal:** One row of text scrolls horizontally at 2 px/VBL using STE HSCROLL.

**New files:**
- `tools/png2font.py` — `font40x34_c1.png` (320×272, 8×8 glyphs) → per-glyph planar pack. Output: 64 glyphs × (40 px padded to 48 px) × 34 rows × 4 bitplanes = 64 × 816 B = 52 KB. Plus extract up to 3 palettes from c1/c2/c3 (palette values only, no bitmap) into separate tables.
- `src/data/font.s` — `incbin 'build/font.bin'` + 3 palette-variant tables (c1/c2/c3)
- `src/data/scroltext.s` — `text_S1: dc.b "              PLEASE, READ ALL THIS SCROLL !!!     ...", 0`
- `src/scroller/engine.s` — `ScrollerInit(a0=text_ptr, d0=row_y)`, `ScrollerStep` (called per VBL). State: `hscroll`, `text_cursor`, `buffer_write_ptr`. On each step: `hscroll += 2`; if `>=16`, `hscroll -= 16`, shift buffer left 1 word, render next glyph into right edge. STE `LINEWID` and `HSCROLL` registers used.

**Done when:** one row of text scrolls smoothly at bottom of logo, music still playing, gradient still visible.

## P6 — Mode A: three parallel rows

**Goal:** S1 and S3 sequences render: three rows, same text, different colors.

**New files:**
- `src/scroller/mode_a_3rows.s` — initializes three scroller instances at Y={82, 122, 162}; `mode_a_render` ticks all three per VBL.

**Modifications:** `src/hbl.s` — extends raster handler to also swap the font palette indices at Y boundaries (82, 116, 122, 156, 162, 196). Palette tables from `data/font.s`.

**Done when:** three rows scroll identical text in three different colors; gradient still visible below row 3.

## P7 — Mode B: big sine scroller + reflection

**Goal:** S2/S4/S6 sequences render: one double-height row with vertical sine wave, flipped reflection below.

**New files:**
- `src/scroller/mode_b_sine.s` — main + reflection sub-render.
- `src/data/sintab.s` — 256-entry signed sine table, amplitude pre-scaled.
- In `src/scroller/engine.s`: add `DrawDoubled` (each source row → 2 dest rows) and `DrawInterline` (each source row → 1 dest row, next dest left clean). Mode B picks which primitive based on sequence (S2/S6 use Interline = chrome; S4 uses Doubled = solid).

**Implementation:** render the scroll text into an off-screen "master" buffer at 40×34 (normal height). For each visible pixel column of the destination, compute `dst_y = base_y + sintab[column + phase]`, copy one column of the master buffer vertically into dest at dst_y, applying the Doubled or Interline primitive. Blitter is ideal for column copies.

**Done when:** big "-- STARGOOSE --" scrolls with sine wobble + mirrored reflection below.

## P8 — Modes C/D/E + 9-sequence sequencer

**Goal:** Full 9-sequence loop plays: S1→S2→...→S9→S1.

**New files:**
- `src/scroller/mode_c_dual.s` — small + big stacked with reflection (S5, S7)
- `src/scroller/mode_d_mixed.s` — small at Y=160 + big sine, no reflection (S8)
- `src/scroller/mode_e_trio.s` — triple layered (S9)
- `src/sequencer.s` — the 9-entry table; `SequencerTick` advances based on `vbl_counter`.

**Sequence table entry format:**
```
  seq_entry:
    dc.l   end_vbl_count     ; absolute VBL count at which this seq ends
    dc.w   mode_id           ; 0=A, 1=B-solid, 2=B-chrome, 3=C, 4=D, 5=E
    dc.l   text_ptr          ; pointer to null-terminated text
    dc.l   fx_params_ptr     ; pointer to mode-specific params (sine amp/freq, Y, ...)
```

**Done when:** all 9 sequences play in order, loop back to S1 after S9 (vbl_counter wraps).
